## Apache Cassandra Data Modeling Project
#  Overview

This project focuses on data modeling using Apache Cassandra, a NoSQL database designed for high availability, scalability, and low-latency operations.

The main goal of this project is to understand how to design efficient data models in Cassandra by applying query-first design principles and denormalization techniques.

## What This Project Includes
Creating Cassandra tables using CQL
Inserting and querying data
Designing schemas based on query requirements
Applying denormalization strategies
Working with primary keys and clustering columns
